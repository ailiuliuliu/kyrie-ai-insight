核心结论
AI 视频是目前单位成本最高、付费转化率最低、规模化路径最模糊的 AI 赛道。当前每生成一个10秒720p视频成本约 $1.30，而构建可持续订阅经济学需要降到 $0.01，差距 130 倍。乐观情景下，Rubin 硬件 × 蒸馏算法叠加，约 2027年底可达临界点；基准情景下，2028年中（$0.04/clip）仅能支撑 B2B 场景，C2C 订阅可能永远无法单独盈利。目前唯一已证明盈利的模式是数字人（HeyGen），因为它靠缓存复用把推理边际成本压到接近零。

⚡ 先从一个反直觉的事实说起

Sora 烧掉 $1M/天，不是因为 OpenAI 运营效率低——那已经是限流后的数字。如果让 Sora 满负荷运行，Cantor Fitzgerald 的分析师测算是 $15M/天。

🔢 原因一：输入复杂度指数级增长

一个10秒720p视频 ≈ 8万个时空 patches（图片只有几百个 token）。Transformer 的计算量与 token 数量是平方关系：patches 翻倍，计算量翻4倍。

分辨率 720p → 4K：成本 ×9
时长 10s → 30s：成本 ×3
两者叠加：4K + 30s ≈ 当前成本 ×27，无任何公司能盈利

🔄 原因二：多轮去噪迭代

DiT 不是一次性生成，是从"噪声"出发做 20–50 次迭代去噪，每次都要处理所有帧。

注意力运算占推理时间的 85% 以上，这是 IRE 引擎（爱诗科技 PixVerse R1）重点优化的环节——把步骤从 50+ 压到 1–4 步，推理成本理论上可降 10–30x。

🏆 为什么 HeyGen 能赚钱：数字人的成本结构根本不同
Open-ended 视频生成数字人（HeyGen）
成本结构每生成一个视频 = 全量推理编码一次 → 缓存复用 N 次
边际成本恒定高（$1.30/clip）趋近于零
类比服务生意（每次重新做）软件生意（编译一次无限分发）

HeyGen Avatar V 架构：用户的身份视频被编码为可复用的「人格嵌入」（personality embedding），在所有后续去噪步骤中被缓存在 KV 级别。第一次生成贵，第 N 次几乎免费。

资本市场在奖励错误模式：HeyGen 融资 $74M 已盈亏平衡，ARR $200M；Synthesia 融资 $536M 仍亏损，ARR $150M。VC 按"增长叙事"估值，但 Sora 关停证明——没有单位经济的增长终将崩塌。
§3 护城河：成本结构差异与 GPU 供给现实
中国成本优势可能被高估
🇨🇳 中国玩家的"隐性补贴"（⚠️ 可能被高估）

H800 / 昇腾910B 比 H100 便宜；国内电力 $0.05/度 vs 美国 $0.10+/度；国家算力补贴直接输血。这带来了明显的定价差距：

可灵 Pro：$0.026/秒｜Runway Pro：$0.09/秒

但华为昇腾 910B 视频推理效率仅为 H100 的 30–40%（软件生态不成熟），国产芯片效率损失基本抵消了电力和人工节省。地缘风险概率 >70% 继续升级，成本护城河比预想更脆弱。
📺 平台型公司的天然优势（真实护城河）

快手是最独特的一个：本身就是内容分发平台。

用可灵生成的视频直接发快手 → 平台内容密度提升 → 广告收入分摊 GPU 成本。Runway / Pika 没有这个结构，纯靠订阅 cover GPU。

Google（Veo + Gemini Flash）同理：模型成本通过 YouTube 广告和 Workspace 订阅摊销。

平台分摊是真实且难以复制的护城河，开源模型打不到这里。

§4 降本路径与杰文斯悖论
基准情景：2028年中 $0.04/clip
🎯 盈利的数学临界点：需要从 $1.30 降到 $0.01

Midjourney 的参照系：图片成本 $0.03–0.05/张，定价 $10–30/月，可生成数百张，毛利率极高。

AI 视频达到 $0.01/clip 时： $20/月订阅 × 100次生成 × $0.01成本 = $1成本 毛利率 = (20-1)/20 = 95% ← 这才是 Midjourney 的世界 现在：$1.30/clip，差 130 倍
情景硬件降本（Rubin）算法降本（蒸馏+量化）叠加后成本预计时间B2B/C2C 可行性
乐观÷10÷13 $0.012027年底 B2B ✅ C2C ✅
基准÷4÷8 $0.042028年中 B2B ✅ C2C ❌
悲观÷2÷3 $0.222029年+ 仅高价值B2B ⚠️
⚠️ 最关键的陷阱：杰文斯悖论

LLM 文本推理成本这 3 年下降了 280 倍，但总推理支出反而上涨了 320%。越便宜 → 越多人用 → 总量指数增长。

视频 vs LLM 的关键区别：LLM 的杰文斯悖论成立，是因为每多一个 API 调用都有明确使用场景（自动化/代码/客服）。视频不同——普通人不会因为成本从 $1.30 降到 $0.01 就每天生成 1000 个视频，除非平台创造分发场景（快手/抖音/TikTok 信息流就是那个场景）。

对可灵的特异性含义：

✅ 受益：成本降 → 快手平台更多 AI 视频内容 → 更多广告库存 → 广告收入分摊 GPU 成本

⚠️ 风险：如果开源压低 C2C 付费，可灵可能只剩平台分摊这一条盈利路径，本质上变成快手生态的「AI 视频基础设施」

对纯工具公司的含义：Runway 2026年7月推出 Media Router（多模型编排），这是"当模型商品化，就做编排层"的转型——同 LLM 领域的 litellm/OpenRouter 逻辑。Pika 没有 orchestration 故事，风险最高。

❌ 尚未跨过阈值的场景

B2B 场景的"够好"标准远低于 C2C 专业创作，这正是 B2B 付费意愿高 10–100 倍的根本原因。

• 电影最终镜头
• 奢侈品品牌主视觉
• 复杂人物表演 & 长时序

竞争焦点已从"谁省"转向"谁有定价权/分发权"

成本下降后，大家都能省。真正的竞争变成：
📺 谁有分发能力（快手/YouTube）→ 生成越多，内容越多，广告越多，正循环
🔒 谁有场景锁定（HeyGen数字人 / Adobe工作流）→ 替换成本高，定价权在
🔧 谁只是工具（Runway/Pika）→ 开源+降价=无定价缓冲，最先被挤出

可灵最可能的终局：盈利不靠用户订阅，而靠平台内嵌 + 广告变现 + B2B API + 数字人的组合——本质上成为快手生态的「AI 视频基础设施」。
