新认知 4：MaaS进入"灰姑娘水晶鞋"竞争阶段

OpenRouter提出的理论正在中国市场验证：AI模型发布第一个月进来的用户留存率极高，产生深度绑定。因此各大厂商（智谱、Kimi、MiniMax、字节、阿里）纷纷推出低价Coding Plan抢先发用户——先用价格吸引，再用迁移成本锁定。

3.1 业务架构：从IaaS到MaaS的三层结构

阿里云不是单一产品，而是三层叠加的云服务体系。MaaS（百炼）不是独立业务，而是建立在IaaS算力之上的服务形态——MaaS的每一次Token消耗，都会带动IaaS层的算力需求，并拉动PaaS层数据库、存储等二阶消费，形成协同飞轮。

MaaS
百炼大模型服务平台
模型调用 / 微调 / RAG / Agent / 多模态 · Token计费 · 增速最快 · FY2027 Q1客户数同比8倍增长
PaaS
开发者平台与数据服务
PolarDB / MaxCompute / ACK容器 / 函数计算 · 传统优势 · 稳定增长 · 被MaaS带动二阶消费
IaaS
基础算力与存储网络
GPU实例 / ECS / OSS / CPFS · 自研平头哥GPU+英伟达混合供应 · AI驱动高端算力需求爆发
🔗 MaaS与阿里云的关系

MaaS是阿里云收入增长的"新引擎"，IaaS/PaaS是"底盘"。客户通过百炼调用模型，背后消耗的是阿里云的GPU算力；客户在百炼上构建知识库，拉动阿里云向量数据库和对象存储的消费。两者高度协同，不可分割。

2026年3月，阿里完成围绕AI的最重要组织重构，形成"通义实验室+阿里云+平头哥"的通云哥战略三角——全球仅阿里与谷歌同时具备大模型、云平台、自研芯片三层全栈能力。

4.4 MaaS的黏性护城河

🔒 为什么迁移成本极高？

· Fine-Tuning锁定：客户在百炼上完成微调后，私有模型数据和训练参数无法迁出
· RAG数据锁定：知识库的向量化数据深度绑定在阿里云向量数据库中，迁移需重建整套索引
· Agent工作流锁定：编排逻辑与阿里云函数计算/云数据库生态深度集成，迁移等于重写
· 结论：进入MaaS全链路服务后，迁移到竞对的隐性成本是显性费用的数倍——这是百炼ARR可持续增长的核心逻辑

  • 2025年实际MaaS营收约15亿元；2026年目标上调至150亿（10倍增速），且目标仍在每月上调

核心短板

💎 五大深度洞察

洞察 1：Token量≠商业价值，50%的Token正在被浪费

现有Token增长高度集中于大模型创业公司（月之暗面/智谱等），本质是"VC资金→算力消耗"的循环。传统大型企业CIO仍以算力成本而非Token价值来决策，MaaS真正渗透传统行业仍是早期。火山引擎49.5%的Token份额只换来约15亿元的MaaS收入，而阿里云28%的份额对应的收入规模远超火山——Token是过程指标，不是结果指标。

洞察 2：阿里云的制度性矛盾正在形成拖累

"云、AI分灶算账"导致ATH自研需要的算力被销售体系优先分配给付费外部客户，Qwen在"排队等卡"。PAI团队2026.6强制并入ATH是补救举措，但制度矛盾能否从根本上解决，决定了阿里云AI飞轮能不能真正自驱。如果内部算力分配问题持续，通义实验室的模型迭代速度将被竞争对手（DeepSeek/字节）拉开差距。

洞察 3："1000亿美元"变成"1000亿元"——目标降调背后的信号

3月电话会说的"五年内云+AI外部收入1000亿美元"，8月已悄然改为"2030年1000亿元人民币（约140亿美元）"，两者差了7倍。这不是笔误，是管理层在资本市场压力下对激进目标的重新锚定。在当前45%的外部云增速下，2030年1000亿元人民币意味着5年CAGR约43%——仍属极高，但比"1000亿美元"这个不可能完成的任务现实得多。

洞察 4：涨价是行业拐点，但客户流失风险被低估

阿里云3月率先涨价终结价格战，这是健康信号。但涨价后哪些客户会迁移到开源自部署方案（Qwen权重开放），哪些会留存，是未来半年最值得跟踪的变量。开源生态悖论：Qwen开源越成功，潜在"反噬"百炼商业化的可能性也越大——客户可以选择下载开源权重自行部署，而非付费使用百炼API。

洞察 5：全球云厂商MaaS同步爆发，竞争参照系转向

AWS Bedrock Q1 2026客户支出环比+170%，Google Cloud Q2 2026增速82%（Vertex AI驱动），MaaS不再是阿里云的差异化——而是全球云厂商的共同叙事。阿里云在海外市场（全球IaaS份额仅4-5%）的增长，是对标AWS Bedrock实现突破的战略窗口，但也是当前最薄弱的环节。真正的竞争不在国内Token份额，而在全球企业级AI服务的商业化能力。

🏁 底线判断

综合评级：谨慎乐观
阿里云是国内AI云市场收入规模最大、全栈能力最完整的玩家，45%的外部收入增速和300亿ARR目标路径清晰，通云哥三角（模型+云+芯片）构建了真正的长期壁垒。

但三个变量值得持续跟踪：① 内部算力分配问题能否在2026年内根本解决；② 涨价后客户留存率数据（FY2027 Q2财报是关键观察点）；③ 百炼ARR能否在FY2027末达到300亿元目标——若达成，MaaS将正式超越IaaS成为阿里云最大收入来源，届时估值逻辑将彻底重构。
